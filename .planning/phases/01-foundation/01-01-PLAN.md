  <files>vite.config.ts, src/index.css</files>
  <action>
Create vite.config.ts with:
- @vitejs/plugin-react with babel plugins array containing:
  - 'babel-plugin-react-compiler' (enables React 19 compiler)
  - observerPlugin() from 'mobx-react-observer/babel-plugin' (auto-wraps observer)
- @tailwindcss/vite plugin for Tailwind v4

Create src/index.css with Tailwind v4 CSS-based configuration:
```css
@import "tailwindcss";
@plugin "daisyui" {
  themes: dracula;
}
```

IMPORTANT: Do NOT create tailwind.config.js - Tailwind v4 uses CSS-based config only.
