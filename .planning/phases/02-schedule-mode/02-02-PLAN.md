     ```typescript
     function handleDragEnd(event: DragEndEvent) {
       const { active, over } = event;
       if (!over) return;

       const activityData = active.data.current;
       const cellData = over.data.current;

       if (activityData?.type === 'activity' && cellData?.type === 'cell') {
         gameStore.assignActivity(
           cellData.patientId,
           cellData.timeSlot,
           activityData.activity.id
         );
       }
     }
     ```

IMPORTANT: The DndContext must wrap BOTH the sidebar (where draggables live) AND the main content (where droppables live). They must share the same context.
